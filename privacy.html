Privacy Policy — Thursday n8n

Last updated: September 29, 2026

Thursday n8n is a personal, single-user app operated by Allen Melara. It is used only with the owner's own Google account.

Data accessed

With the owner's consent, the app uses the Gmail API to read, organize, draft and send email in the owner's own mailbox.

How data is used and stored

Email data is processed only to run the owner's own automations. OAuth tokens and any processed data are stored only on the owner's own computer, in a self-hosted n8n instance. No data is sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
